Three-Tier Web Application on AWS

Designed and deployed a secure three-tier web application architecture on AWS consisting of presentation, application, and database layers.

  • Provisioned a public Linux EC2 instance as the web server and a private Linux EC2 instance as the application server running a Python Flask service on port 5000.
  • Integrated Amazon RDS (SQL) as the managed database to store and retrieve user login data.
  • Configured domain hosting, created a hosted zone, and mapped the domain to a public Application Load Balancer secured with an SSL certificate.
  • Implemented traffic flow from the public load balancer to the web tier and an internal load balancer between web and application tiers for secure private communication.
  • Set up VPC networking, security groups, and IAM roles to enforce controlled access across layers.
  • Created Auto Scaling Groups across multiple Availability Zones within a single region to improve availability, scalability, and fault tolerance.
  • Gained hands-on experience with load balancing, network security, high availability, and end-to-end DevOps deployment workflows.
